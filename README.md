# 🎬 BingeBuddy

### Netflix Series Recommendation System

BingeBuddy is a simple **Java-based series recommendation system** that helps users discover series based on their mood. It also allows users to view all available series and search for a specific series.

## ✨ Features

* 📺 View all available series
* 🎭 Get recommendations based on mood
* 🔍 Search for a series by name
* ⭐ Display series ratings
* 🌐 Display genre and language information
* 🚪 Simple menu-driven interface

## 🎯 How It Works

The program displays a menu with four options:

```text
1. View All Series
2. Get Recommendation
3. Search Series
4. Exit
```

### Mood Recommendation

The user can select a mood:

```text
1. Dark
2. Exciting
3. Funny
4. Light
```

BingeBuddy then searches the series database and displays series matching the selected mood.

### Search

Users can enter a series name, and BingeBuddy searches the database for matching titles.

## ▶️ How to Run

Make sure Java is installed on your computer.

Open the project folder in the terminal and compile:

```bash
javac Main.java Series.java SeriesDatabase.java
```

Then run:

```bash
java Main
```
